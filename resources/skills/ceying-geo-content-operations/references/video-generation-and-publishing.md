# GEO 视频生成

## 使用场景

用户要求短视频推广、生成品牌视频、产品介绍视频、案例讲解视频、行业科普视频，或在获客推广方案中需要执行视频内容动作时，使用本流程。当前 ceying-geo MCP 只负责创建视频生成任务和查询生成结果，不负责发布到抖音、B站、小红书、快手、视频号等自媒体平台。

## 前置判断

1. 先确认是否发现 `geo_create_video` 和 `geo_get_video`。
2. 创建视频需要 `videos:write`，查询已有视频需要 `videos:read`。
3. 没有视频工具时，进入 [mcp-server-setup.md](mcp-server-setup.md)，引导用户补充视频生成相关 Scope。
4. 用户只要视频选题、脚本或发布策略，不要求执行平台动作时，可以先输出方案，但不得声称已经创建视频。
5. 用户要求发布视频到自媒体时，说明当前 ceying-geo MCP 不提供视频发布工具，只能先完成视频生成并返回视频地址。

## 执行流程

1. 明确视频目标：品牌曝光、产品介绍、案例讲解、行业科普、获客转化或活动传播。
2. 收集最少信息：品牌或产品、行业、目标客户、核心卖点、视频主题、口播脚本、画面关键词、比例和生成数量。
3. 生成内容方案：先给标题、脚本、镜头重点和封面建议；事实不足时标注为待验证建议。
4. 创建视频：经用户确认会消耗视频生成额度后，调用 `geo_create_video`，保存视频任务编号和幂等键。
5. 查询结果：调用 `geo_get_video`，直到状态为 `success`、`failed` 或出现明确错误；不要把创建成功当成生成完成。
6. 生成成功后返回 `first_video_url`、`videos`、`combined_videos`、状态、进度和失败原因字段。生成失败时说明原因和可重试范围。

## 输入建议

创建视频时优先构造以下字段：

- `subject`：一句话视频主题，必须明确品牌、产品或场景。
- `script`：口播或旁白脚本。没有脚本时先生成并让用户确认。
- `terms`：正向画面关键词，适合填行业、场景、产品、办公室、生产、服务等素材方向。
- `negative_terms`：不希望出现的画面或风格。
- `video_aspect`：短视频默认 `9:16`，横版内容使用 `16:9`，方形素材使用 `1:1`。
- `video_count`：默认 1，除非用户明确要多版本测试。
- `cover_image`：可选封面图地址，只作为视频任务元数据，不代表发布动作。

## 确认规则

调用 `geo_create_video` 前必须先确认，因为会按 `video_count` 消耗视频生成额度。

同一次创建网络重试必须保持相同 `idempotency_key` 和相同请求参数。用户改变主题、脚本、比例或生成数量时必须使用新的幂等键。

## 输出格式

执行前：

- 视频目标
- 视频主题和脚本摘要
- 视频比例和生成数量
- 额度影响
- 需要用户确认的创建动作

执行后：

- 视频任务编号、状态、进度和视频地址
- 封面图字段
- 失败原因或下一次查询建议
- 下一步复盘指标

## 复盘指标

- 生成侧：视频是否成功、生成耗时、封面是否匹配、脚本是否清晰。
- 内容侧：主题是否贴合品牌定位、画面关键词是否准确、是否适合目标平台的内容风格。
- 增长侧：后续投放或人工发布后的曝光、播放、完播、互动、评论线索、咨询来源、AI 搜索提及变化。
