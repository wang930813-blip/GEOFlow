# GEO 视频生成

## 使用场景

用户要求短视频推广、生成品牌视频、产品介绍视频、案例讲解视频、行业科普视频、活动传播视频，或说“做一条视频”“把这个脚本生成视频”“查视频结果”“看看视频生成好了没有”时，直接使用本流程。

当前 ceying-geo MCP 只负责创建视频生成任务和查询生成结果，不负责发布到抖音、B站、小红书、快手、视频号等自媒体平台。

## 直达触发

| 用户表达 | 直接动作 | 工具 |
| --- | --- | --- |
| 生成品牌视频、做一条短视频、把脚本生成视频 | 创建视频生成任务并等待结果 | `geo_create_video` -> `geo_get_video` |
| 查视频生成结果、看视频进度、视频好了没有 | 查询视频任务详情 | `geo_get_video` |
| 查视频任务列表、看最近生成的视频 | 查询视频任务列表 | `geo_list_videos` |
| 给我视频脚本、短视频选题、画面建议 | 输出内容方案，不调用写工具 | 无 |

命中创建或查询动作时，不先输出完整品牌增长路线图。

## 前置判断

1. 创建视频需要发现 `geo_create_video` 和 `geo_get_video`，并具备 `videos:write` 与 `videos:read`。
2. 只查询已有视频时需要发现 `geo_get_video` 或 `geo_list_videos`，并具备 `videos:read`。
3. 没有视频工具时，进入 [mcp-server-setup.md](mcp-server-setup.md)，引导用户补充视频生成相关 Scope。
4. 用户只要视频选题、脚本或发布策略，不要求执行平台动作时，可以先输出方案，但不得声称已经创建视频。
5. 用户要求发布视频到自媒体时，说明当前 ceying-geo MCP 不提供视频发布工具，只能完成视频生成并返回视频地址。

## 创建视频

1. 收集最少信息：品牌或产品、视频主题、核心卖点、目标客户、脚本或口播方向、画面关键词、比例和生成数量。
2. 缺少脚本时，可以先生成脚本摘要并让用户确认；用户已经给出脚本时，不重新扩展成长方案。
3. 告知本次 `video_count` 会消耗对应视频生成额度，等待用户确认。
4. 调用 `geo_create_video`，保存视频任务编号、请求参数和 `idempotency_key`。
5. 立即调用 `geo_get_video` 查询同一视频任务。
6. 状态为 `queued` 或 `processing` 时继续查询，不重复创建视频任务。
7. 状态为 `success` 时返回生成结果。状态为 `failed` 或出现明确错误时返回失败原因和可重试范围。

## 结果闭环

生成视频必须返回生成结果，不能只回复“任务已创建”。

成功结果至少返回：

- 视频任务编号。
- `status` 和进度字段。
- `first_video_url`。
- `videos`。
- `combined_videos`。
- 封面图字段。
- 生成数量和视频比例。

失败结果至少返回：

- 视频任务编号。
- `status` 和进度字段。
- 失败原因字段。
- 是否可以沿用原主题、脚本、比例和数量重试。

如果客户端单轮等待受限，应先返回已创建的视频任务编号、当前状态和下一次必须调用 `geo_get_video` 的说明；下一轮继续查询该任务，不重新创建。

## 输入建议

创建视频时优先构造以下字段：

- `subject`：一句话视频主题，必须明确品牌、产品或场景。
- `script`：口播或旁白脚本。没有脚本时先生成并让用户确认。
- `terms`：正向画面关键词，适合填行业、场景、产品、办公室、生产、服务等素材方向。
- `negative_terms`：不希望出现的画面或风格。
- `video_aspect`：短视频默认 `9:16`，横版内容使用 `16:9`，方形素材使用 `1:1`。
- `video_count`：默认 1，除非用户明确要多版本。
- `cover_image`：可选封面图地址，只作为视频任务元数据，不代表发布动作。

## 确认规则

调用 `geo_create_video` 前必须先确认，因为会按 `video_count` 消耗视频生成额度。

同一次创建网络重试必须保持相同 `idempotency_key` 和相同请求参数。用户改变主题、脚本、比例或生成数量时必须使用新的幂等键。

## 输出格式

创建前：

- 视频主题。
- 脚本摘要。
- 视频比例和生成数量。
- 额度影响。
- 需要用户确认的创建动作。

创建后：

- 视频任务编号。
- 状态和进度。
- `first_video_url`、`videos`、`combined_videos`。
- 封面图字段。
- 失败原因或下一次查询动作。

## 复盘指标

- 生成侧：视频是否成功、生成耗时、封面是否匹配、脚本是否清晰。
- 内容侧：主题是否贴合品牌定位、画面关键词是否准确、是否适合目标平台的内容风格。
- 增长侧：后续人工发布后的曝光、播放、完播、互动、咨询来源、AI 搜索提及变化。
