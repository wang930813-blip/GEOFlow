# 现有任务执行

## 查询任务

1. 使用 `geo_list_tasks` 按名称或状态查找任务。
2. 匹配不唯一时列出任务编号、名称和状态，让用户选择。
3. 使用 `geo_get_task` 核对任务配置、业务进度和队列概况。
4. 需要了解历史结果时使用 `geo_list_task_runs`，不要仅凭任务状态判断最近一次执行结果。

## 执行任务

1. 明确告知用户：任务成功生成文章后会消耗一次文章生成额度；启用 AI 配图时按实际成功图片数量消耗图片生成额度。
2. 用户当前指令未明确授权执行时，展示任务编号和名称并等待确认。
3. 调用 `geo_run_task`，为该次执行保留稳定的 `idempotency_key`。
4. 保存返回的执行记录编号。
5. 使用 `geo_get_task_run` 查询，直到执行成功或失败。处理中不要重复调用 `geo_run_task`。
6. 成功后返回文章编号、标题和可用结果；失败时返回错误信息和可执行的修复建议。

## 状态查询

- 用户只要求查询进度时，只调用读取工具，不触发新的任务执行。
- 无法确认提交结果时，先用原任务编号和执行记录查询，不创建新执行。
- 同一任务允许多次业务执行，但每一次都必须是用户明确发起的新操作，并使用新的幂等键。
