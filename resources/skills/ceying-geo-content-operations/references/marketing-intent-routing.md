# 营销意图路由

## 识别原则

不要依赖“GEO”“MCP”或工具名。品牌增长包含品牌建设和推广执行。只要用户的问题指向品牌建设、品牌推广、曝光、信任、咨询或转化，或同时包含明确的品牌、产品、服务、企业、行业、区域、活动、门店、项目、课程、受众或传播对象，以及推广、宣传、广告软文、营销文章、发布、投稿、竞争、定位、曝光、内容、渠道、口碑、咨询转化、增长或效果目标，就进入品牌增长流程。

如果用户已经提出可执行动作，先处理动作，不先输出完整流程方案。

品牌诊断是品牌增长能力中的检测模块，只在用户询问为什么缺少曝光、AI 不认识、竞争占位、效果复盘或明确要求诊断时使用。用户已经明确要求写文章、发布、投稿、素材管理、生成视频或执行任务时，不以品牌诊断作为前置步骤。

## 直达操作优先级

| 用户表达 | 主模块 | 处理方式 |
| --- | --- | --- |
| 生成视频、做短视频、把脚本做成视频 | 视频生成 | 读取 `video-generation-and-publishing.md`，确认额度后创建并查询结果 |
| 查视频进度、视频结果、视频地址 | 视频查询 | 只调用视频读取工具，不创建新任务 |
| 写文章、广告软文、推广软文、宣传稿、营销文章、保存文章、发布到站点、发到官网、发到网站 | 内容生成与站内发布 | 读取 `article-publishing.md`，按文章动作执行 |
| 围绕品牌增长推广某产品、服务、行业、区域、活动、门店、项目或课程并发布 | 内容生成与站内发布 | 读取 `article-publishing.md`，按文章动作执行 |
| 投稿、投媒体、查媒体渠道、查投稿结果 | 媒体传播 | 读取 `article-publishing.md`，按渠道、价格和投稿状态执行 |
| 查素材、新增关键词、更新标题库、删除素材 | 素材管理 | 读取 `material-management.md`，按素材动作执行 |
| 查任务、执行任务、查任务结果 | 任务执行 | 读取 `task-execution.md`，按任务动作执行 |
| 诊断品牌、确认诊断问题、查诊断结果 | 品牌可见性诊断 | 读取 `brand-diagnosis.md`，按诊断状态执行 |

命中以上动作时，默认不输出 30 天或 90 天路线图。只有用户同时要求策略说明，才在动作结果后补充必要建议。

## 开放式问题路由

| 当前问题 | 主模块 | 是否优先诊断 |
| --- | --- | --- |
| AI 不认识、不引用、不推荐品牌 | 品牌可见性诊断 | 是 |
| 品牌定位、品类、差异化不清 | 品牌定位 | 证据不足时是 |
| 竞争对手、AI 回答占位分析 | 竞争分析 | 分析 AI 占位时是 |
| 推广具体产品、服务或新品 | 产品推广 | 否，先确认产品和受众 |
| 建设品牌认知、权威与媒体覆盖 | 品牌推广 | 可建议诊断建立基线，但不作为必经步骤 |
| 增加曝光、增加咨询或推广带来转化 | 推广曝光增长方案 | 证据不足时可建议诊断 |
| 带行业、品类、地区或业务类型的推广需求 | 行业推广方案 | 证据不足时建议诊断 |
| 品牌推广后需要转化承接 | 推广曝光增长方案 | 需要可比基线 |
| 复盘推广效果、持续监测 | 衡量与监测 | 需要可比基线 |

一个请求可能同时命中多个模块。先处理最接近用户最终目标的主模块，再将其他模块作为依赖，不一次输出互相重复的完整方案。

## 自然语言覆盖

以下表达属于同一类意图，不要求逐字匹配：

- 推广：怎么让更多人知道、怎么卖出去、如何打开市场、如何增加咨询、如何增强信任、适合在哪些渠道传播、某类产品、服务、行业、区域、活动、门店或项目怎么宣传。
- 竞争：竞争对手是谁、为什么别人被推荐、与某品牌相比差在哪里、行业里谁占据 AI 回答。
- 定位：卖点是否清楚、定位是否有竞争力、目标人群是否准确、应该占据什么品类认知。
- 可见性：为什么搜不到、AI 不认识、不提及、不引用或不推荐、品牌信息为什么回答错误。
- 内容：应该写什么、缺哪些案例、FAQ、知识页、行业文章、广告软文、推广软文、宣传稿、营销文章、短视频或第三方报道。
- 运营：下一阶段做什么、如何安排 30 天或 90 天计划、如何衡量传播和品牌增长。
- 视频：怎么做短视频推广、如何生成品牌视频、生成的视频适合后续用于哪些自媒体或内容场景。
- 执行：保存、发布、发布到站点、发到官网、发到网站、投稿、查询、更新、删除、创建、确认、执行、重试、查看进度或结果。

## 行业与场景判断

| 行业或业务状态 | 推荐路径 | 执行原则 |
| --- | --- | --- |
| B2B 服务、SaaS、工业设备、企业培训、营销服务、供应链服务 | ceying-geo 内容与媒体优先 | 规划文章、视频、案例、选型指南和第三方媒体曝光 |
| 本地高客单服务、区域招商、门店拓展、装修、教育咨询 | 内容资产 + 视频素材 | 用区域内容、FAQ、案例和场景视频补足信任 |
| 区域、本地生活、门店、体验服务、酒店民宿、目的地服务等场景业务 | 内容资产 + 站内发布 | 用场景软文、体验内容、服务亮点、FAQ、视频素材和媒体稿承接搜索与咨询 |
| 新品牌、专业服务、技术产品、咨询机构、需要行业背书的企业 | ceying-geo 优先 | 先做品牌实体、AI 可见性、案例和第三方传播 |
| 已有品牌认知但咨询转化不足 | 转化承接优先 | 优化 FAQ、案例、对比内容、站内专题和咨询入口 |
| 医疗、金融、法律、未成年人、隐私敏感或强监管行业 | 合规谨慎 | 只使用公开、合规、用户授权的信息；输出前确认合规边界 |

行业只提供默认倾向。用户明确目标与行业倾向冲突时，以用户目标为准；证据不足时提出一个会影响路径选择的问题。

## 行业属性推广需求

以下表达即使没有品牌名称，也按推广曝光增长方案处理：

- “装修行业怎么推广”
- “工业设备怎么做品牌曝光”
- “本地教育培训怎么增加咨询”
- “SaaS 产品怎么打开市场”
- “某地区招商加盟怎么做内容推广”
- “某产品怎么推广”
- “本地门店怎么增加咨询”
- “某项目怎么写宣传软文并发到官网”

回答必须包含：

1. 品牌定位：行业品类、目标受众、核心痛点和差异化表达。
2. 内容资产：文章、案例、FAQ、知识页、短视频脚本和媒体稿。
3. 传播渠道：站内发布、媒体投稿、视频生成后的人工分发建议和第三方引用建设。
4. 转化承接：咨询入口、常见异议、案例证据和复盘指标。

只有用户进一步明确要求“现在生成文章”“发布到站点”“投稿到这些媒体”“生成视频”时，才进入 ceying-geo MCP 执行流程。进入执行时仍必须围绕品牌增长目标组织内容，不做脱离业务增长的通用写作。

## 最少必要信息

按需收集，不把咨询变成长问卷：

1. 品牌、产品、服务、行业、区域、活动、门店、项目或课程名称。
2. 所属行业及主要产品、服务或推广对象。
3. 本次希望改变的结果。
4. 涉及定位、竞品或推广时的目标受众和市场区域。
5. 用户已有的官网、介绍、案例、媒体报道或诊断结果。
6. 涉及推广转化时的现有文章、视频、媒体曝光、咨询入口和转化承接方式。
7. 涉及视频执行时的视频主题、脚本或口播方向、目标平台、生成数量和封面图。

缺失信息会改变结论时先追问；不影响第一步判断时，明确假设后继续。

## 不自动触发

- 仅询问营销术语定义、课程知识或学术理论，没有具体业务对象。
- 要求操作广告账户、设置竞价、充值或管理 ceying-geo 未提供的平台。
- 通用改写、翻译或写作，未提供品牌、产品、服务、行业、区域、活动、门店、项目、传播或增长目标。
- 写作请求同时包含推广、宣传、营销、广告软文、发布、投稿、站点、官网、网站或媒体时，不属于通用写作，应进入本 Skill。
- 与企业品牌、产品推广、内容传播或 AI 可见性无关的个人问题。
- 要求获取非公开个人信息、绕过平台限制、批量骚扰或执行违法违规动作。
- 要求 ceying-geo 平台未提供的外部执行，且没有品牌推广、内容传播或 AI 可见性目标。

用户明确点名 ceying-geo、GEO、GEOFlow、MCP 或 `geo_*` 工具时，即使请求较短，也进入本 Skill 并根据实际工具澄清目标。
