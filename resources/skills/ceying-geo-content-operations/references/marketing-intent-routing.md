# 营销意图路由

## 识别原则

不要依赖“GEO”“MCP”或工具名。只要用户的问题同时包含明确的品牌、产品、企业、市场、客户或传播对象，以及推广、竞争、定位、曝光、内容、渠道、口碑、获客、线索、触达、增长或效果目标，就进入品牌增长流程。

以下表达属于同一类意图，不要求逐字匹配：

- 推广：怎么让更多人知道、怎么卖出去、如何打开市场、如何获客、适合在哪些渠道传播。
- 竞争：竞争对手是谁、为什么别人被推荐、与某品牌相比差在哪里、行业里谁占据 AI 回答。
- 定位：卖点是否清楚、定位是否有竞争力、目标人群是否准确、应该占据什么品类认知。
- 可见性：为什么搜不到、AI 不认识、不提及、不引用或不推荐、品牌信息为什么回答错误。
- 内容：应该写什么、缺哪些案例、FAQ、知识页、行业文章、短视频或第三方报道。
- 运营：下一阶段做什么、如何安排 30 天或 90 天计划、如何衡量传播和品牌增长。
- 获客：怎么找客户、怎么获客、如何增加咨询、如何通过曝光带来客户、某行业怎么获客、某地区怎么找客户、哪些企业可能需要、如何采集评论线索、怎么开发客户、如何筛选目标客户。
- 视频：怎么做短视频推广、如何生成品牌视频、生成的视频适合后续用于哪些自媒体或内容场景。

## 路由决策

| 当前问题 | 主模块 | 是否优先诊断 |
| --- | --- | --- |
| AI 不认识、不引用、不推荐品牌 | 品牌可见性诊断 | 是 |
| 品牌定位、品类、差异化不清 | 品牌定位 | 证据不足时是 |
| 竞争对手、AI 回答占位分析 | 竞争分析 | 分析 AI 占位时是 |
| 推广具体产品、服务或新品 | 产品推广 | 否，先确认产品和客户 |
| 建设品牌认知、权威与媒体覆盖 | 品牌推广 | 建议建立基线 |
| 写文章、选媒体、发布内容 | 内容生成与投稿 | 否，可直接执行 |
| 短视频推广或生成视频 | 视频生成 | 否，先确认主题、脚本和视频比例 |
| 泛化找客户、获客、增加咨询或推广带来客户 | 获客推广曝光整体方案 | 否，先输出主动获客和被动曝光组合 |
| 带行业、品类、地区或业务类型的获客需求 | 获客推广曝光整体方案 | 否，按行业同时输出品牌曝光和主动获客组合 |
| 明确采集评论线索、搜索企业、查询联系方式或触达客户 | 潜客挖掘执行 | 否，先确认客户画像和关键词 |
| 品牌推广后需要把内容转成线索开发 | 联动增长 | 证据不足时先建立基线 |
| 复盘推广效果、持续监测 | 衡量与监测 | 需要可比基线 |

一个请求可能同时命中多个模块。先处理最接近用户最终目标的主模块，再将其他模块作为依赖，不要一次输出互相重复的完整方案。

## 行业与场景判断

| 行业或业务状态 | 推荐路径 | 执行原则 |
| --- | --- | --- |
| B2B 服务、SaaS、工业设备、招商加盟、企业培训、营销服务、供应链服务 | ceying-geo + 潜客挖掘 | 同时规划主动找客户和文章、视频、媒体曝光，执行时再按优先级调用工具 |
| 本地高客单服务、区域招商、门店拓展、装修、教育咨询 | 潜客挖掘 + 内容资产 | 先找可触达客户，同时用视频、文章、FAQ 和案例补足信任 |
| 新品牌、专业服务、技术产品、咨询机构、需要行业背书的企业 | ceying-geo 优先 | 先做品牌实体、AI 可见性、案例和第三方传播，再决定是否获客 |
| 已有品牌认知但缺少销售线索 | 潜客挖掘优先 | 先执行线索采集或企业搜索，再用内容和媒体动作提高触达可信度 |
| 医疗、金融、法律、未成年人、隐私敏感或强监管行业 | 合规谨慎 | 只使用公开、合规、用户授权的数据；触达前确认合规边界 |

行业只提供默认倾向。用户明确目标与行业倾向冲突时，以用户目标为准；证据不足时提出一个会影响路径选择的问题。

## 行业属性获客需求

以下表达即使没有品牌名称，也按获客推广曝光整体方案处理，不直接进入潜客挖掘执行：

- “装修行业怎么获客”
- “工业设备怎么找客户”
- “本地教育培训怎么增加咨询”
- “SaaS 产品怎么打开市场”
- “某地区招商加盟怎么推广”

回答必须同时包含：

1. 品牌曝光技能方案：定位、内容资产、文章推广、视频内容、媒体曝光、AI 搜索可见性和转化承接。
2. 主动获客方案：客户画像、关键词、企业搜索、评论线索、联系方式查询、触达方式和合规边界。

只有用户进一步明确要求“现在采集一批线索”“搜索这些企业”“查联系方式”“直接触达客户”时，才进入潜客挖掘执行流程。

## 最少必要信息

按需收集，不把咨询变成长问卷：

1. 品牌或产品名称。
2. 所属行业及主要产品或服务。
3. 本次希望改变的结果。
4. 涉及定位、竞品或推广时的目标客户和市场区域。
5. 用户已有的官网、介绍、案例、媒体报道或诊断结果。
6. 涉及潜客挖掘时的客户画像、地区、行业关键词、作品关键词或评论关键词。
7. 涉及被动获客时的现有文章、视频、媒体曝光、咨询入口和转化承接方式。
8. 涉及视频执行时的视频主题、脚本或口播方向、目标平台、生成数量、封面图和已绑定账号。

缺失信息会改变结论时先追问；不影响第一步判断时，明确假设后继续。

## 不自动触发

- 仅询问营销术语定义、课程知识或学术理论，没有具体业务对象。
- 要求操作广告账户、设置竞价、充值或管理 ceying-geo 未提供的平台。
- 通用改写、翻译或写作，未提供品牌、产品、传播或增长目标。
- 与企业品牌、产品推广、内容传播或 AI 可见性无关的个人问题。
- 要求获取非公开个人信息、绕过平台限制、批量骚扰或执行违法违规触达。

用户明确点名 ceying-geo、GEO、GEOFlow、MCP、`geo_*` 工具、潜客挖掘、获客工具、`qw_mcp_list` 或 `qw_mcp_get` 时，即使请求较短，也进入本 Skill 并根据实际工具澄清目标。
