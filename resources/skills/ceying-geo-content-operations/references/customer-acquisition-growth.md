# 获客推广曝光整体方案

## 使用场景

用户提出“我要找客户”“怎么获客”“怎么推广能带来客户”“怎么增加曝光和咨询”“我的产品怎么打开市场”等泛化增长目标时，先使用本流程。用户提出带行业、品类、地区或业务类型的获客需求时，也先使用本流程，例如“装修行业怎么获客”“工业设备怎么找客户”“本地教育培训怎么增加咨询”。不要直接回答“使用潜客挖掘 Skill 和 MCP”，也不要把获客等同于采集线索。

本流程将获客拆成四层：

1. **主动找客户**：通过潜客挖掘、企业搜索、评论线索采集和客户触达主动获得可跟进对象。
2. **被动吸引客户**：通过品牌定位、文章推广、视频内容、媒体曝光和 AI 搜索可见性，让目标客户主动看到并咨询。
3. **内容承接转化**：用官网知识页、案例、FAQ、对比文章、视频脚本、私信话术和评论回复承接客户疑问。
4. **持续复盘优化**：按曝光、线索、互动、咨询、成交和 AI 答案占位复盘，不把单次采集当成完整获客。

## 回答原则

1. 先给整体方案，再说明可执行工具；不要把 MCP 工具当成方案本身。
2. 同时覆盖主动获客和被动获客；除非用户明确只要其中一类。
3. 根据行业选择重点。只要用户问题包含行业属性和获客目标，回答必须同时包含品牌曝光技能方案和主动获客方案，不能只输出线索采集动作。
4. 高客单、强信任、长决策业务更重视内容和品牌背书；短周期、本地化、明确需求业务可以先做主动线索，但仍要说明被动曝光如何补充获客。
5. 不能声称 ceying-geo 已自动执行视频发布。视频推广可以输出选题、脚本、标题、分发建议和复盘指标；只有实际发现视频相关工具时才执行平台动作。
6. 用户未提供行业、产品或目标客户时，先基于已知信息给一版通用结构，再只追问会影响执行路径的一个关键问题。

## 默认回答结构

当用户只说“我要找客户”或类似表达时，按以下结构回答：

1. **当前判断**：这不是单纯采集名单的问题，而是“主动获客 + 被动曝光 + 内容承接”的组合问题。
2. **主动找客户动作**：
   - 明确目标客户画像、行业、地区和需求关键词。
   - 使用潜客挖掘 MCP 执行评论线索采集、企业搜索、联系方式查询或客户触达。
   - 输出线索后生成触达话术、评论回复或私信内容。
3. **被动获取客户动作**：
   - 用 ceying-geo 做品牌可见性诊断，确认 AI 是否理解品牌、产品和优势。
   - 规划文章推广：品牌知识页、行业问题文章、案例文章、FAQ、选型对比、媒体稿。
   - 规划视频推广：短视频选题、脚本、标题、口播卖点、评论区承接话术。
   - 通过媒体投稿、文章分发和持续内容更新增加曝光。
4. **转化承接动作**：
   - 准备统一品牌介绍、产品卖点、案例证据、常见异议回复和咨询入口。
   - 主动触达时引用已发布内容或案例，降低陌生客户的不信任。
   - 被动曝光带来的咨询，用 FAQ、案例和对比内容缩短决策周期。
5. **优先级建议**：
   - 线索紧急时，先主动获客，同时补最小内容资产。
   - 品牌认知弱时，先做诊断和内容资产，再放大触达。
   - 行业信任成本高时，先建立案例、媒体和专业观点，再扩展线索。
6. **可执行动作与确认点**：
   - 潜客挖掘执行前确认关键词、地区、数量、触达方式和合规边界。
   - ceying-geo 投稿、诊断、删除或消耗额度动作前确认费用、额度或影响。
7. **衡量指标**：
   - 主动获客看线索数、有效线索率、回复率、转化率。
   - 被动获客看曝光量、搜索提及、AI 答案占位、文章阅读、咨询来源。

## 行业属性获客回答结构

当用户的问题包含行业属性时，按该行业场景改写默认回答，不要输出泛泛模板：

1. **行业获客判断**：说明该行业客户决策特点、信任成本、主动线索可行性和被动曝光价值。
2. **品牌曝光技能方案**：
   - 定位：明确行业品类、目标客户、核心痛点和差异化表达。
   - 文章推广：行业问题文章、案例文章、选型对比、FAQ、媒体稿和知识页。
   - 视频推广：场景短视频、客户痛点、案例讲解、避坑指南、口播脚本和评论区承接。
   - 媒体曝光：行业媒体、本地媒体、垂直平台、第三方报道和可被 AI 引用的内容资产。
   - AI 搜索可见性：品牌诊断、品牌实体信息、竞品占位问题和答案优化。
3. **主动获客方案**：
   - 客户画像：行业、地区、岗位、企业规模、需求信号和预算阶段。
   - 线索来源：企业搜索、经营范围、评论区、竞品内容、行业活动、区域关键词。
   - 触达动作：评论回复、私信、电话、邮箱、企微或内容引导，按行业合规边界选择。
4. **联动执行顺序**：
   - 线索紧急：先主动获客，同时准备最小品牌资料、案例和FAQ。
   - 品牌弱：先做品牌曝光和内容资产，再放大主动触达。
   - 两者都重要：先输出一周、三十天、九十天节奏。
5. **MCP 执行边界**：
   - 品牌曝光和内容资产执行使用 ceying-geo 的 `geo_*` 工具。
   - 线索采集、企业搜索和触达执行使用潜客挖掘 MCP。
   - 未要求执行工具时，只给方案和下一步确认点。

## 行业场景化重点

| 行业或业务 | 主动获客重点 | 被动获客重点 |
| --- | --- | --- |
| B2B 服务、SaaS、工业设备 | 企业搜索、经营范围匹配、行业痛点关键词 | 选型指南、案例文章、技术解释、媒体背书 |
| 招商加盟、本地服务、教育培训 | 地区、需求评论、竞品评论、目标人群线索 | 短视频场景内容、FAQ、成功案例、区域媒体 |
| 专业服务、咨询、法律财税 | 企业名单、职位或需求关键词、行业活动线索 | 专业观点、可信来源、案例拆解、问答内容 |
| 新消费、生活方式、文旅门店 | 评论线索、达人评论区、城市兴趣关键词 | 视频种草、体验文章、用户评价、活动内容 |
| 医疗、金融、未成年人相关行业 | 只处理公开合规线索，触达前确认边界 | 科普内容、资质说明、风险提示、合规审查 |

## 与 MCP 的关系

本流程本身是方案编排，不要求先安装任何 MCP。

需要执行品牌诊断、素材、文章、媒体投稿或结果查询时，检查 ceying-geo 的 `geo_*` 工具。需要执行线索采集、企业搜索、联系方式查询或客户触达时，检查潜客挖掘 MCP 的 `qw_mcp_list`、`qw_mcp_get` 和目标工具。

如果用户只要方案，不调用 MCP。如果用户要求“现在帮我开始找客户”“直接采集一批线索”“帮我投稿发布文章”，再进入对应执行流程。
