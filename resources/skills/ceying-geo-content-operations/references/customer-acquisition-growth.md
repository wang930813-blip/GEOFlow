# 推广曝光增长方案

## 使用场景

用户提出“怎么推广能带来咨询”“怎么增加曝光和咨询”“我的产品怎么打开市场”“某行业怎么推广”“某地区怎么做品牌曝光”等泛化增长目标时，先使用本流程。用户没有要求立即执行平台动作时，先给策略；需要读取数据、创建内容、投稿、发布或生成视频时，再检查 ceying-geo 的 `geo_*` 工具。

本流程将增长拆成四层：

1. **品牌认知基础**：统一品牌实体、官网信息、产品描述、案例证据和 FAQ。
2. **内容资产建设**：通过知识页、行业问题文章、案例文章、选型对比、视频脚本和媒体稿解释品牌价值。
3. **传播与引用**：通过站内发布、媒体投稿、视频生成和第三方内容扩大可信引用。
4. **咨询转化承接**：用统一介绍、案例、常见异议、咨询入口和复盘指标承接曝光后的咨询。

## 回答原则

1. 先给整体方案，再说明可执行工具；不要把 MCP 工具当成方案本身。
2. 聚焦 ceying-geo 能支持的品牌诊断、内容资产、视频生成、文章站内发布、媒体投稿和结果查询。
3. 根据行业选择重点。高信任、长决策业务更重视案例、专业观点和第三方引用；本地或强场景业务更重视视频内容、区域内容和咨询入口。
4. 视频推广先输出选题、脚本、标题、分发建议和复盘指标；实际发现视频相关工具并获得用户确认后，可以通过 ceying-geo 创建视频并查询生成结果，不声称已发布到自媒体。
5. 用户未提供行业、产品或目标受众时，先基于已知信息给一版通用结构，再只追问会影响执行路径的一个关键问题。

## 默认回答结构

当用户只说“我要增加曝光”“怎么推广能带来咨询”或类似表达时，按以下结构回答：

1. **当前判断**：这是“品牌认知 + 内容资产 + 传播渠道 + 转化承接”的组合问题。
2. **品牌基础动作**：
   - 明确品牌实体、产品品类、服务对象、核心问题和差异化表达。
   - 用品牌诊断确认 AI 是否理解品牌、产品、优势和竞品位置。
   - 统一官网、企业介绍、产品页、案例和 FAQ 的事实口径。
3. **内容与视频动作**：
   - 规划品牌知识页、行业问题文章、案例文章、选型对比、FAQ 和媒体稿。
   - 规划短视频选题、口播脚本、标题、画面关键词和评论区承接说明。
   - 需要执行时调用文章、视频或任务工具，记录编号和状态。
4. **传播动作**：
   - 将适合公开的文章发布到 GEO 用户站点。
   - 对需要第三方背书的内容查询媒体渠道、核对价格并在授权后投稿。
   - 按内容主题、媒体可信度和可持续引用价值选择渠道，不以数量替代质量。
5. **转化承接动作**：
   - 准备统一品牌介绍、产品卖点、案例证据、常见异议回复和咨询入口。
   - 对站内文章、媒体稿和视频使用一致的品牌事实和行动引导。
   - 用 FAQ、案例和对比内容缩短咨询后的决策周期。
6. **优先级建议**：
   - 品牌认知弱时，先做诊断和内容资产。
   - 需要快速曝光时，优先站内发布、媒体稿和短视频内容。
   - 信任成本高时，先建立案例、媒体和专业观点，再扩展传播频次。
7. **可执行动作与确认点**：
   - ceying-geo 投稿、诊断、删除、视频生成或消耗额度动作前确认费用、额度或影响。
8. **衡量指标**：
   - 看 AI 答案占位、品牌提及、引用来源、文章阅读、媒体发布、视频生成结果、咨询来源和复测变化。

## 行业属性推广回答结构

当用户的问题包含行业属性时，按该行业场景改写默认回答，不要输出泛泛模板：

1. **行业推广判断**：说明该行业决策特点、信任成本、内容教育难度和第三方背书价值。
2. **品牌曝光方案**：
   - 定位：明确行业品类、目标受众、核心痛点和差异化表达。
   - 文章推广：行业问题文章、案例文章、选型对比、FAQ、媒体稿和知识页。
   - 视频推广：场景短视频、客户痛点、案例讲解、避坑指南、口播脚本和后续人工发布建议。
   - 媒体曝光：行业媒体、本地媒体、垂直平台、第三方报道和可被 AI 引用的内容资产。
   - AI 搜索可见性：品牌诊断、品牌实体信息、竞品占位问题和答案优化。
3. **转化承接方案**：
   - 明确咨询入口、服务范围、案例证据、常见异议和下一步行动。
   - 将文章、视频和媒体稿的行动引导保持一致。
4. **执行顺序**：
   - 第一周：品牌事实梳理、诊断、基础文章和视频脚本。
   - 三十天：持续文章站内发布、媒体投稿、视频生成和复测诊断。
   - 九十天：围绕高价值问题扩展内容矩阵和第三方引用。
5. **MCP 执行边界**：
   - 品牌曝光、内容资产、文章站内发布、媒体投稿和视频生成执行使用 ceying-geo 的 `geo_*` 工具。
   - 未要求执行工具时，只给方案和下一步确认点。

## 行业场景化重点

| 行业或业务 | 内容资产重点 | 传播重点 |
| --- | --- | --- |
| B2B 服务、SaaS、工业设备 | 选型指南、案例文章、技术解释、实施流程 | 行业媒体、白皮书、专业观点、AI 问题占位 |
| 招商加盟、本地服务、教育培训 | 区域内容、FAQ、成功案例、场景视频 | 本地媒体、短视频素材、站内专题页 |
| 专业服务、咨询、法律财税 | 专业观点、可信来源、案例拆解、问答内容 | 垂直媒体、专家观点、合规说明 |
| 新消费、生活方式、体验类门店 | 体验文章、活动内容、用户评价、场景视频 | 本地媒体、生活方式内容、视频素材 |
| 医疗、金融、未成年人相关行业 | 科普内容、资质说明、风险提示、合规审查 | 权威来源、谨慎措辞、复核流程 |

## 与 MCP 的关系

本流程本身是方案编排，不要求先安装任何 MCP。

需要执行品牌诊断、素材、文章、文章站内发布、媒体投稿、视频生成或结果查询时，检查 ceying-geo 的 `geo_*` 工具。

如果用户只要方案，不调用 MCP。如果用户要求“帮我投稿发布文章”“生成一条品牌视频”“查询诊断结果”，再进入对应执行流程。
