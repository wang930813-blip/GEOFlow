# 产品推广

## 规划步骤

1. 确认产品或服务、目标客户、购买场景、市场区域、推广目标、周期和可用证据。
2. 判断推广阶段：认知建立、需求教育、方案比较、信任验证或购买转化。一次计划优先解决一个主阶段。
3. 将产品信息整理为实体定义、客户问题、能力机制、差异化、使用场景、案例证据和常见问题。
4. 识别客户在 AI 搜索中可能提出的品牌词、品类词、问题词、比较词和决策词。
5. 设计与决策阶段匹配的内容资产和传播渠道，不把单篇软文当作完整推广方案。
6. 对需要发布的内容，先使用 ceying-geo 查询素材、作者、分类、文章状态、媒体实时信息和视频任务，再按确认规则执行文章站内发布、文章投稿或视频生成。

## 内容资产组合

| 目标 | 优先资产 |
| --- | --- |
| 让 AI 理解产品 | 产品知识页、实体说明、能力边界、术语定义 |
| 建立需求关联 | 问题解决文章、场景指南、行业 FAQ |
| 支持方案比较 | 对比框架、选型指南、适用与不适用场景 |
| 建立可信度 | 客户案例、数据证据、资质、第三方报道 |
| 支持决策 | 实施流程、交付范围、常见异议、成功标准 |
| 扩大触达 | 短视频脚本、视频生成、文章站内发布、媒体曝光、评论区承接 |

## 输出格式

- 产品推广目标与阶段
- 目标客户和核心场景
- 当前信息与证据缺口
- 信息架构和内容主题
- 自有内容与第三方传播组合
- 30 天优先动作
- 90 天扩展动作
- ceying-geo 可执行的素材、文章、文章站内发布、任务、视频生成和投稿动作
- 衡量指标

用户只要求直接创建或投稿内容时，不强制输出完整推广计划，但必须确保文章目标、受众、事实依据和渠道清楚。
