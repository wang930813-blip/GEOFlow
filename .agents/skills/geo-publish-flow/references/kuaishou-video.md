# 快手视频发布

## 使用场景

目标平台为快手（`KWAT`），且内容类型为视频时读取本文档。

## 必要检查

- 当前用户/租户在宿主应用中已有已授权的快手账号绑定。
- 视频媒体 URL 是公网可访问地址，或已通过三方平台上传并确认。
- `publishAt` 是未来的 ISO 8601 时间。

## 最小发布项

```json
{
  "platform": "KWAT",
  "accountId": "current-user-kwat-account-id"
}
```

不要复制抖音、B 站、小红书的 options。快手如果需要 options，必须来自三方平台的平台结构。

## 状态处理

快手通常走标准发布轮询流程：

- 待处理/发布中：继续轮询。
- 成功：返回作品链接。
- 失败/取消：返回平台错误、code、requestId 和可用的 record id。

如果未来三方平台为快手返回用户操作链接，按抖音的方式处理，但要明确说明该链接用于快手。
