## 运行时适配

- 新主题由现有 `SiteThemeCatalog` 按 manifest 自动发现，并复用现有主题预览参数。
- `SitePageUrl` 将主题页面标识映射到 GEOFlow 当前命名路由，并保留有效的主题预览参数。
- `Template01Data` 将当前站点设置、联系信息和产品分页映射到公共主题数据；纯文本介绍会先转义再输出，产品原始 Markdown 不进入主题详情字段。
- `SiteThemeData` 兼容数组和对象两种主题数据访问方式。
- `SiteThemeViewResolver` 将 GEOFlow 的产品列表视图名映射到标准主题 `products.blade.php`。
- JSON-LD 与 SEO head 复用主题所需的本地安全输出组件和 partial。
