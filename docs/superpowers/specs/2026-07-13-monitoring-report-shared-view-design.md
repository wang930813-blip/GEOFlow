# 监测报表分享页固定展示设计

## 目标

公开分享链接只展示创建分享时选中的报表。分享页页头不提供报表切换下拉框，也不输出另一个报表的入口；登录后台查看报表时仍保留现有切换菜单和分享按钮。

## 方案

`MonitoringReportRenderer` 接收明确的公开分享页标记，并将该标记传给企业舆情和行业竞争力两个 Blade 视图。

- 后台报表：渲染现有 `<details class="report-menu">` 切换菜单。
- 公开分享页：渲染不可交互的当前报表名称标签，不渲染 `<details>`、下拉箭头或其他报表链接。
- 分享快照的数据、Token、公开访问权限和 URL 格式保持不变。

采用服务端条件渲染，不使用 CSS 隐藏或 JavaScript 禁用，避免另一个报表入口残留在公开页面 DOM 中。

## 验证

- 企业舆情分享页只包含企业舆情报表固定标签。
- 行业竞争力分享页只包含行业竞争力报表固定标签。
- 两种分享页均不包含 `report-menu` 下拉结构和另一个报表链接。
- 后台报表仍包含 `report-menu` 和分享按钮。
- 现有公开分享和快照测试继续通过。
